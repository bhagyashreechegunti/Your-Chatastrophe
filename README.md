# Chatastrophe

A local-first micro-app that helps users quickly understand and prioritize important information from long chat conversations.

## Features

- Paste a chat thread or long conversation
- Automatically identify key updates, decisions, actions, and deadlines
- Highlight urgency and priority signals
- Keep all processing on-device with no external API dependency

## Run locally

Open `index.html` in a browser, or from the project folder run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Overview

Chatastrophe is a simple AI-inspired micro-app that helps users quickly understand and prioritize important information from overwhelming chat conversations.
